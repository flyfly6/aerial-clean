# AerialClean TV 桌面静态壁纸与 Dock 样式美化

## Goal

在现有 `lite/` 原生 Android TV 桌面架构基础上，实现静态壁纸体系（必应每日精选与 14 张内置自然风景壁纸）、壁纸采样分辨率选择设置（720p / 1080p / 4K）、屏幕下方常用应用玻璃底板 Dock 与全部应用网格双层流转交互，以及针对 Android 4.4（minSdk 19）低端硬件的性能降级适配。

## Background

- 当前版本实现了最基础的核心可用性：纯深色渐变背景（`BackdropView`），首排横向 Dock + 下方网格直接平铺，所有 App 在同一屏滚动，缺少壁纸支持且首屏视觉层次较单调。
- 用户期望参考 `aerial-tv` 优雅的视觉与交互意图（精美壁纸、下方悬浮玻璃 Dock、常用与全部应用分层流转），美化桌面样式。
- 我们已通过 Pencil 在 [`design.pen`](./design.pen) 绘制了 1080p 高保真设计图（详见设计预览 [`design-preview.md`](./design-preview.md)），定义了 4 个主要屏幕与状态：
  1. **首屏常驻桌面**：静态壁纸 + 顶部极简大时钟/日期 + 底部常用应用玻璃 Dock（焦点高亮呼吸光晕）+ 向下探索提示；
  2. **全部应用网格**：按遥控器【方向下键】平滑展开完整 6 列网格，背景自动叠加深色暗角遮罩保障图标文字清晰；
  3. **壁纸与显示设置面板**：按【菜单键】呼出弹窗，配置壁纸来源、分辨率采样等级（720p/1080p/4K）、底板样式及 14 张内置壁纸预览选择；
  4. **架构设计规范与 4.4 性能保证**。

## 用户与场景

- 老旧智能电视或盒子（Android 4.4~7.0，512MB~1GB 内存，双核/四核芯片），连接 720p/1080p 或 4K 电视大屏。
- 坐在 2~3 米开外的客厅，完全通过红外/蓝牙遥控器操作（D-Pad 方向键、OK 确认键、返回键、菜单键）。
- 期望既有现代大屏桌面的高级通透感（高清壁纸、精致底板、显眼焦点），又绝不卡顿、绝不被系统作为高内存后台杀掉。

## 范围

### 做

| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-1 | **静态壁纸加载与缓存系统**：支持必应每日精选（Bing Daily Wallpaper），后台异步拉取 Bing API 并落盘缓存至应用私有目录，冷启动直读本地缓存，断网秒开 0 阻塞 | 启动时先读缓存，离线不崩溃，拉取成功自动平滑替换 |
| FR-2 | **14 张内置自然/航拍壁纸**：内置打包 14 张高品质风景与航拍静态壁纸（WebP 格式压缩），纯离线零网络依赖 | 离线可自由选图，支持定时轮换或手动固定 |
| FR-3 | **三档分辨率动态采样设置**：支持 720p、1080p、4K 采样率配置。通过 `BitmapFactory.Options.inSampleSize` 与 `RGB_565` 格式解码，严格控制内存 | 720p 下壁纸 Bitmap 内存 < 3MB；1080p < 9MB；切换壁纸主动 `recycle()` |
| FR-4 | **首屏双层布局架构**：首屏仅展示大时钟与屏幕下方常用应用 Dock；按遥控器【方向下键】平滑滚动至全部应用网格 | 首屏干净开阔，常用与全部应用流转自然 |
| FR-5 | **常用应用玻璃 Dock**：悬浮圆角底板，放置 5~7 个高频应用；遥控器焦点项放大 1.08x，带有柔和天空蓝呼吸光晕外框与立体高亮底板 | 焦点在 3 米外一眼可辨，左右边界阻断防丢焦 |
| FR-6 | **遥控器按键导航流转**：<br>- 在 Dock 按 `DOWN`：平滑滚动进入全部应用网格；<br>- 在网格第一行按 `UP` 或在网格中按 `BACK`：平滑收回至常用 Dock；<br>- 在任何界面按 `MENU`：呼出“桌面壁纸与显示设置”面板；<br>- 在常驻桌面按 `BACK`：拦截事件不退出桌面 | 全遥控器单层流畅闭环操作 |
| FR-7 | **全部应用沉浸网格**：向下展开时，背景壁纸平滑叠加 85% 深色暗角遮罩；标准 6 列网格排列，配右侧极简滚动指示条 | 应用图标文字高对比度呈现，快速滚动无撕裂 |
| FR-8 | **桌面壁纸与显示设置面板**：提供直观设置弹窗：<br>1. 壁纸来源（必应每日 / 14张内置 / 纯净渐变）；<br>2. 分辨率选择（720p / 1080p / 4K）；<br>3. 底板样式（磨砂毛玻璃 / 半透磨砂黑 / 极速极简）；<br>4. 14 张内置壁纸横向画廊预览选择器 | 所有选项即时生效，并持久化到 `LayoutStore` |
| FR-9 | **玻璃底板 4.4 性能降级**：Android 4.4 硬件无 RenderEffect，提供“半透磨砂黑”（85% 半透明深色 + 1.5px 白色高光描边）作为极速默认替代 | 纯 Canvas 硬件加速直出，0 模糊算法开销，老电视稳跑 60fps |
| FR-10 | **网络权限按需处理**：为支持必应每日壁纸与轻量天气拉取，安全声明 `android.permission.INTERNET`，但保持零遥测、零更新检查，无网环境 100% 优雅降级 | 静态代码无任何追踪 SDK |
| FR-11 | **三行经典信息排版与天气农历**：左上角采用 Outfit 现代无衬线大时钟（84sp），同行搭配公历、星期与农历月日（1900-2050纯算法计算），第三行异步拉取 Open-Meteo 实时天气；右上角采用设置齿轮按钮与纯矢量网络连接图标 | 优雅对齐 aerial-tv 质感，断网优雅展示降级缓存 |
| FR-12 | **常用 Dock 精密居中与对称内边距**：Dock 左右预留安全边距，移除底部多余“全部应用 ▾”文字；磁贴圆角改小为 12dp/10dp，垂直方向严格对称内边距（上下各 20dp，获焦放大各 14dp）；槽位不足或存在隐藏应用时自动从应用列表中按序精准补齐 | 杜绝大屏溢出，遥控器交互对称自然 |
| FR-13 | **带壁纸背景的时钟防烧屏屏保**：桌面闲置 60 秒自动触发 `ClockSaver`，背景绘制当前壁纸并叠加 75% 沉浸深色防烧屏遮罩，Outfit 大时钟与日期定时微幅漂移 | 任意按键唤醒退出，防 OLED/LCD 烧屏 |

### 不做

| 项 | 原因 | 去处 |
|---|---|---|
| 动态视频壁纸 / 4K 航拍视频循环播放 | Android 4.4 电视芯片大多无 HEVC 硬解，常驻解码会导致 CPU/GPU 满载发热与丢按键 | 后续版本评估作为独立闲置屏保（ScreenSaver） |
| 局域网 Web 手机扫码传图 | 涉及内置微型 HTTP 服务器与 Android 4.4 旧 WebView 兼容问题 | v3 评估 |
| 桌面小组件 (AppWidgetHost) | 复杂度高，电视场景实用价值低 | 不做 |
| 多屏左右翻页模式 | TV 遥控器上下单轴流转体验最佳，不增加左右翻屏认知成本 | 不做 |

## 约束

- **C1** 基线不变：`minSdk 19`、`compileSdk 34`、`targetSdk 28`，所有代码通过 Java 8 语法实现，不引入 Kotlin 运行时。
- **C2** 核心依赖保持受控：`androidx.core:core:1.13.1` 与 `androidx.recyclerview:recyclerview:1.3.2`，不新增抬高 minSdk 的第三方大库。
- **C3** 严格内存控制：
  - 解码强制采用 `Bitmap.Config.RGB_565`（老版本每像素 2 字节）；
  - 720p 采样下全屏壁纸仅占约 1.8MB；1080p 约 4.1MB（RGB_565 下每张图 `1920*1080*2 = 4,147,200 bytes`）；
  - 切换壁纸必须在主线程置换前/后主动对旧 Bitmap 调用 `recycle()`；
  - 80 个已安装 App 时常驻 PSS 控制在 60MB 以内。
- **C4** APK 体积预算：14 张内置自然壁纸采用 WebP 75 压缩打包，单图 < 120KB，14 张总增量控制在约 1.5MB 左右，Release APK 总体积保持在 2.5MB 以内。
- **C5** 闪电启动：冷启动首帧耗时 < 1.5s。冷启动优先读取当前选定壁纸的本地解码缓存或渐变色，严禁在 `onCreate` / 主线程发起网络请求。
- **C6** Lint 静态闸门：`./gradlew :app:lintDebug`，`NewApi` 必须 0 error。

## 验收标准

- **A1** 构建与静态检查：`cd lite && ./gradlew :app:assembleDebug` 与 `./gradlew :app:lintDebug` 成功通过，`NewApi` 保持 0 error。
- **A2** 桌面首屏与 Dock 呈现：启动后首屏为高质量壁纸背景 + 大时钟与日期 + 悬浮圆角 Dock，遥控器在 Dock 磁贴切换时光标放大 1.08x 并带有明显呼吸光晕。
- **A3** 双层平滑流转：在 Dock 最下一行按遥控器 `DOWN` 键平滑滚动展示全部应用网格，背景自动叠加深色暗角；在网格第一排按 `UP` 键或按 `BACK` 键平滑收回至常用 Dock。
- **A4** 设置面板呼出与交互：按遥控器 `MENU` 键可随时呼出“桌面壁纸与显示设置”面板，按 `BACK` 键关闭面板并自动持久化设置。
- **A5** 壁纸来源与离线可用性：
  - 切换为“14 张内置自然精选”时，可通过缩略图选择器直接更换壁纸，断网状态下 100% 正常；
  - 切换为“必应每日精选”时，后台成功下载并落盘，断网再次启动仍能正确展示本地缓存壁纸。
- **A6** 分辨率采样验证：在设置中切换 720p / 1080p / 4K，查看内存 dump 确认对应的 Bitmap 尺寸与内存占用符合计算预期。
- **A7** 性能降级验证：在 Android 4.4 设备/模拟器上，选择“半透磨砂黑”底板，方向键快速连续滚动 60 秒无掉帧、无内存泄漏、无 ANR。
- **A8** Release 打包体积：`./gradlew :app:assembleRelease` 产出的 Release APK 体积小于 2.5MB。

## 风险与兜底

| 风险 | 影响 | 兜底 |
|---|---|---|
| 必应每日壁纸 API 域名在中国大陆或特定局域网偶发无法直连 | 无法拉取最新每日壁纸 | 自动兜底读取本地最近一次成功缓存；若本地无缓存，自动回退到内置壁纸第一张，并 Toast 提示用户，绝不白屏崩溃 |
| 14 张内置壁纸增加 APK 体积 | 超出极致体积预算 | 采用 WebP 75 压缩算法，尺寸统一限制为 1080p 分辨率，单张仅 80~120KB，总增量严格控制在 1.5MB 以内 |
| 低配 512MB 老电视在 4K 分辨率壁纸下发生 OOM | 系统强杀 Launcher | 内存分级预警：检测设备可用内存若低于 1GB，设置项中给 4K 标注“高内存预警”，且默认推荐 720p/1080p；每次切换壁纸显式调用 `Bitmap.recycle()` |
| 遥控器快速向下穿透丢焦 | 焦点在 Dock 与网格间跳飞 | 在 RecyclerView 与 Dock 布局容器中显式声明 `descendantFocusability="afterDescendants"` 并重写方向导航按键分发 |
